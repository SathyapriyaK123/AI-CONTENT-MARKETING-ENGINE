\# Frontend Documentation



\## How to Use



1\. Start the backend servers:

```bash

start\_workers.bat

```



2\. Open in browser:

```

http://localhost:8000/frontend/index.html

```



\## Features



\- Blog post generation with tone control

\- Tweet generation (multiple variants)

\- Full campaign generation with progress tracking

\- SEO tools (metadata, keywords, quality analysis)

\- Real-time progress updates

\- Responsive design



\## Sections



1\. \*\*Blog Post\*\* - Generate blog posts with custom word count and tone

2\. \*\*Tweets\*\* - Generate multiple tweet variants

3\. \*\*Full Campaign\*\* - Generate blog + tweets + Instagram + LinkedIn

4\. \*\*SEO Tools\*\* - Analyze content and generate SEO metadata
